A userscript that adds keybind functionality to Internet Roadtrip! ~~Now you can throw your mouse away!~~

Features:
- Selecting options by number (from left to right)
- Selecting the leftmost, forwardmost, and rightmost option
- Seeking
- Honking
- Turning on/off radio
- Turning up/down the radio volume by 5 volume units
- Expanding/contracting map
- Opening/closing chat window
- Opening/closing Discord server
- Choosing the most popular option (Bandwagon)
